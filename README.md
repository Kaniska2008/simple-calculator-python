SIMPLE CALCULATOR USING PYTHON

Project Title:
Simple Calculator Using Python

Programming Language:
Python 3.13

Objective:
To create a simple calculator that performs basic mathematical operations.

Operations:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)

Features:
- Performs basic mathematical calculations.
- Handles division by zero.
- Detects invalid operators.
- Allows the user to perform multiple calculations.
- Uses a while loop to repeat the calculator.

How It Works:
The program asks the user to enter two numbers and an operator.
Based on the operator entered, the program performs the required
mathematical operation and displays the result.

Conclusion:
This project helped me understand Python basics such as variables,
input, conditional statements, loops, and basic error handling.
